# Generic Agent Adapter

This adapter applies when a runtime has tools but no dedicated integration guidance.

## Minimum integration contract

1. Load `SKILL.md` before evidence-heavy project work.
2. Load only references relevant to the current mode.
3. Load a project profile only when its identity is unambiguous.
4. Map read tools to evidence gathering and write tools to authorized implementation.
5. Never infer write authority from tool availability.
6. Require separate protected-action authorization for protected assets/actions.
7. Preserve direct verification evidence for claims of success.
8. Apply cumulative carry-forward regression in release work.

If the runtime cannot enforce these boundaries mechanically, follow them procedurally and report any limitation that affects verification confidence.

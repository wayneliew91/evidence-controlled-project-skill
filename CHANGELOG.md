# Changelog

## 1.1.0 — 2026-08-12

Distilled lessons from a long-running evidence-heavy rebuild into generic governance without adding project/company-specific data.

- Added fact-specific evidence authority and current-truth vs historical-truth separation.
- Added explicit retirement handling so stale specs/tests cannot keep superseded features active.
- Added canonical identity vs source-label rules for former names, aliases, and historical snapshots.
- Added transaction-semantic rules: settlement evidence does not define claim/payment type.
- Added one-economic-event ownership to prevent cross-module revenue/cost duplication.
- Added typed-adjustment preservation instead of flattening materially different deductions.
- Added traceable evidence consolidation with provider-native IDs, lineage, duplicate/version classification, and sensitive-data exclusions.
- Added dependency-first reconstruction guidance for heavily damaged central modules while preserving frozen integrations.
- Added delivery-first closure rules, release-blocker classification, stale-verifier handling, and single-candidate convergence.
- Expanded project profile template, ChatGPT/Codex adapters, generic profile examples, pressure scenarios, and deterministic validation.

## 1.0.0 — 2026-08-12

Initial public distilled release.

- Added read-only-by-default project governance.
- Added two-level authorization for ordinary and protected actions.
- Added evidence hierarchy with lineage-aware conflict resolution.
- Added non-blocking `UNRESOLVED` handling and scope control.
- Added frozen-capability reopening contract.
- Added direct-evidence verification and cumulative release regression.
- Added ChatGPT, Codex, Claude, and generic-agent adapters.
- Added synthetic project profile, pressure scenarios, and deterministic validation.

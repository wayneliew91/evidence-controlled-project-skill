# Evidence Register

Recommended columns/fields:

| Field | Purpose |
|---|---|
| Evidence ID | Stable local reference |
| Source System | Mail, drive, repository, paper record, etc. |
| Source ID | Provider-native message/file/record ID |
| Original Name | Original artifact label |
| Evidence Type | Primary / derived / historical / generated |
| Canonical Mapping | Entity/project/event mapping, if confirmed |
| Lineage | Parent source, duplicate hash, transformed copy, or supersession |
| Review Status | Unreviewed / verified / unresolved / superseded |
| Notes | Conflict, scope, or source-specific meaning |

The register indexes evidence; it never replaces authoritative originals.

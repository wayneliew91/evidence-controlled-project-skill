# Current Truth

## Active rule example

**Current rule:** Legacy Category A is retired from new/current records.

**Supersedes:** Older specification and screenshots that still show Category A as selectable.

**Current surfaces:** New-entry UI, current validation, active reports, and regression expectations must not require Category A.

**Historical preservation:** Existing historical records may retain the original label as immutable evidence.

## Rule

A current product decision changes current behavior without rewriting historical source evidence.
